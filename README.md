# TinSports

A comprehensive sports information and event management website showcasing multiple sports disciplines, news updates, and community engagement.

## About TinSports

TinSports is a modern, responsive sports platform designed to bring together sports enthusiasts, event information, and news in one centralized hub. Whether you're interested in cricket, football, basketball, or volleyball, TinSports provides detailed information, upcoming events, and the latest sports news.

## Features

- **Multiple Sport Categories** - Coverage of popular sports including:
  - Cricket
  - Football
  - Basketball
  - Volleyball

- **Event Management** - Browse and explore upcoming sports events with detailed information

- **Sports News** - Stay updated with the latest sports news and highlights

- **About & Contact** - Learn more about our mission and get in touch with the community

- **Responsive Design** - Fully responsive interface optimized for desktop and mobile devices

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/realnazmul/tinsports.git
   ```

2. Navigate to the project directory:
   ```bash
   cd tinsports
   ```

3. Open `index.html` in your web browser to view the website

## Pages Overview

- **Home** (`index.html`) - Main landing page with featured sports and navigation
- **Sports Sections** - Individual pages for each sport discipline
- **Events** - Comprehensive event listing and details
